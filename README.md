**✨ MEMS 与微系统研究热点及发展趋势分析——文献计量学作业 ✨**

**项目简介**
本项目聚焦于 **MEMS（Micro-Electro-Mechanical Systems，微机电系统）与微系统** 领域的研究现状、热点主题与发展趋势，采用文献调研与文献计量分析相结合的方法，系统梳理并定量分析近年来相关学术成果。

MEMS 与微系统是信息技术、传感技术、微纳制造及智能系统的核心交叉领域，广泛应用于消费电子、汽车电子、生物医学、航空航天、工业控制、环境监测等场景。随着微纳工艺、集成技术、智能传感及低功耗设计的进步，该领域研究持续扩展。本项目通过结构化分析，旨在为学术研究与工程实践提供科学参考。

**研究背景**

- **多学科交叉**：融合机械、电子、材料、控制、传感、制造等领域。
- **研究热点驱动因素**：
    1. 微纳加工工艺成熟
    1. 传感器小型化、集成化与智能化需求激增
    1. 物联网、可穿戴设备、智慧医疗等场景驱动应用扩展
    1. 新材料、新结构、新封装方法涌现
    1. 与 AI、边缘计算、柔性电子、生物芯片的交叉研究增多

**核心目标**

1. **发文趋势分析**：解析年度发文量及阶段性发展特征。
2. **作者/机构/合作网络**：识别高产学者、核心机构及合作模式。
3. **关键词共现与演化**：挖掘热点主题（如传感器、微流控、生物医学应用等）及时间演变。
4. **技术路径分析**：基于高被引文献与网络分析，梳理关键技术路线。
5. **问题与趋势总结**：归纳当前挑战与未来发展方向。

**研究方法**
**流程**：检索 → 筛选 → 数据清洗 → 分析 → 可视化
**关键步骤**：

1. **文献检索**：
    - 数据库：Web of Science、Scopus、IEEE Xplore、ScienceDirect、SpringerLink
    - 关键词：MEMS、microsystems、micro-sensors、micro-actuators、microfabrication等
2. **筛选机制**：
    - 双阶段筛选（标题/摘要初筛 + 全文复筛）
    - 规则化代码辅助，确保可复现性
3. **数据清洗**：
    - 去重、标准化（作者、机构、关键词）、消歧、异常值处理
4. **分析维度**：
    - 发文量、作者/机构分布、合作网络、关键词共现、主题演化、高被引分析、共被引/文献耦合网络
5. **结果呈现**：表格、统计图表、网络图、流程图 + 结构化报告
