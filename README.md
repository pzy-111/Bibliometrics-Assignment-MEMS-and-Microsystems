📄 执行摘要
本项目基于文献计量学方法，对 MEMS（微机电系统）与微系统 领域的学术文献进行了系统性挖掘。通过分析关键词聚类、突现时序、合作网络及里程碑论文，我们识别出该领域已形成“制备—材料—行为—设计—性能”的完整知识体系。研究发现，力学行为（Behavior） 是核心枢纽，而 微机械器件（Micromechanical Devices） 和 柔性传感 正在成为当前爆发强度最高的前沿热点。以下是基于数据分析的核心洞察。
🔍 核心研究发现
1. 知识结构全景：关键词聚类分析
基于图一关键词聚类图分析，MEMS领域呈现出高度关联的知识网络结构。
核心枢纽：Behavior（力学行为） 是绝对中心节点，串联起材料、制造、设计与性能全链条。
四大稳定分支：
左侧（工艺/材料）：聚焦 Fabrication（制备）与 Films（薄膜材料）。
右侧（设计/优化）：聚焦 Design（设计）与 Performance（性能）。
演化路径：研究主题长期稳定，核心方向延续性强，从早期的蓝紫色节点向近年的红黄色节点平滑过渡。
